## ✦ The Vision

EMBER represents the intersection of thermal science and human craftsmanship. This project was developed as a technical and design showcase, prioritizing art direction, smooth interactions, and high-fidelity rendering over standard e-commerce patterns.

Inspired by the tactile precision of Leica, the curated simplicity of Aesop, and the high-end digital craftsmanship of modern editorial magazines.

### Art Direction Highlights
- **True Dark UI:** Ink-black voids punctuated by "Heat-Map" gradients.
- **Cinematic Typography:** Utilizing `Bebas Neue` for architectural impact and `Geist` for technical precision.
- **Atmospheric Depth:** Custom SVG film grain overlays and glassmorphic surfaces.

---

## ✦ Technical Implementation

Built for performance and visual fidelity, utilizing the latest frontend architecture.

### Tech Stack
- **Framework:** Next.js 15 (App Router, Static HTML Export)
- **Styling:** Tailwind CSS v4 (with strict adherence to the design system variables)
- **Animation:** Framer Motion (Scroll reveals, magnetic button physics)
- **3D Graphics:** React Three Fiber & Drei

### Key Features
1. **Procedural WebGL Hero:** A custom GLSL shader simulating the slow, rolling heat of espresso crema and steam, reacting dynamically.
2. **Interactive 3D Ritual:** A centerpiece pour-over experience utilizing PBR materials (brushed copper, glass, ceramic) and HDR environment lighting.
3. **Magnetic Interactions:** Custom physics-based cursor interactions on primary calls-to-action.
4. **Editorial Layouts:** Fluid typographic scaling and strict baseline grid adherence.
